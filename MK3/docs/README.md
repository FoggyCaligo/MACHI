# MK3 Docs Index

이 폴더의 문서는 `MK3`를 다음 기준으로 이해하도록 돕는다.

- 왜 사용자 중심 기억 구조만으로는 부족했는가
- 왜 기억 대상을 세계 전체로 넓혀야 했는가
- 왜 그래프를 단순 저장소가 아니라 사고 공간으로 쓰려 했는가
- 왜 전체 그래프가 아니라 국소 활성화 그래프가 필요했는가

추천 순서는 아래와 같다.

1. `../README.md`
2. `architecture/MK3_overview.md`
3. `guid/MK3_전체정리.md`
4. `handoff/MK3_handoff.md`
5. `todo/MK3_다음작업_로드맵.md`

문서를 읽을 때의 핵심 전제는 간단하다.

> `MK3`는 사용자 기억만 다루는 시스템이 아니라, 세계를 그래프로 이해하고 그 위에서 사고하는 구조를 세우려는 단계다.
