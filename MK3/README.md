# MK3

`MK3`는 사용자 기억에 집중하던 구조를 넘어, AI가 사용자만이 아니라 **세상 자체를 이해하고 기억하고 확장할 수 있게** 아키텍처를 다시 짜는 단계다.

출발점은 분명하다. `MK2`는 사용자에 대한 인상, 성향, 정정, 근거를 다루는 데는 의미가 있지만, 기억의 범위가 사실상 **사용자 모델**에 묶여 있었다. 대화에서 등장하는 개념, 사물, 사실, 관계, 외부 정보 전체를 같은 구조 안에서 다루기에는 부족했다.

`MK3`는 이 한계를 해결하기 위해, 기억의 대상을 사용자에서 세계 전체로 넓히고, 그 위에서 그래프를 통한 사고를 직접 수행하는 쪽으로 넘어간다.

## 목표

`MK3`의 목표는 다음과 같다.

> 사용자의 말과 외부 세계를 모두 그래프로 옮기고, 그 그래프 위에서 국소적으로 활성화된 부분을 중심으로 사고하게 만든다.

즉 이 단계에서 해결하려는 문제는 두 가지다.

- 기억의 대상이 사용자 프로필에만 갇히는 문제
- 기억은 있어도 그 기억 위에서 직접 사고하지 못하는 문제

## 기능

### 1. 세계 대상 그래프 기억

- 사용자 관련 정보만 저장하지 않는다.
- 대화에서 등장한 개념, 사실, 관계, 작업 맥락을 함께 그래프에 올린다.

### 2. 단어 중심 노드 구성

- 그래프의 기본 노드를 단어 수준에서 만든다.
- 의미는 단어들 사이의 연결 구조를 통해 드러나게 한다.

이 단계의 핵심 아이디어는 "개념을 일단 단어 노드들로 세우고, 의미를 그 단어들 사이의 연결에서 다룬다"는 것이다.

### 3. 국소 활성화 그래프

- 전체 그래프를 매번 다 쓰지 않는다.
- 현재 입력과 가까운 주변만 활성화해서, 그 국소 그래프 안에서 사고를 진행한다.

즉 `MK3`는 거대한 전체 그래프보다, **현재 질문에 의해 불이 켜진 부분 그래프**를 사고의 작업 공간으로 사용한다.

### 4. 사고와 언어화의 분리

- 먼저 그래프에서 결론 구조를 만든다.
- 그 다음 그 결론만 언어로 풀어낸다.

답변은 문장을 바로 이어 쓰는 것이 아니라, 그래프 안에서 추린 결론의 언어화 결과다.

## 작동방식

`MK3`의 기본 흐름은 아래와 같다.

```text
사용자 입력
-> 입력을 그래프로 적재
-> 현재 입력 주변의 국소 활성화 그래프 구성
-> 활성 그래프 위에서 사고/판정
-> 필요하면 검색 보강
-> 결론 그래프 구성
-> 결론만 언어화
```

이 구조에서 중요한 점은, 사고의 중심이 프롬프트나 대화 로그가 아니라 **활성화된 부분 그래프**라는 점이다.

## 기억구조

`MK3`의 기억 구조는 `MK2`의 evidence/profile 중심 구조와 다르게, 세계를 구성하는 노드와 연결을 중심에 둔다.

### 1. 단어 노드

- 입력에서 나온 단어를 그래프의 기본 진입 단위로 사용한다.
- 각 단어는 장기 그래프 안에서 반복적으로 재사용된다.

### 2. 관계 연결

- 의미는 단어 하나가 아니라 단어들 사이의 연결에서 나타난다.
- 사실, 문맥, 작업 단서도 연결 구조로 보존된다.

### 3. 활성화된 부분 그래프

- 현재 턴에서는 전체 그래프 대신, 관련 노드 근처만 불러온다.
- 이 부분 그래프가 실제 사고의 작업 메모리 역할을 한다.

즉 `MK3`의 기억은 "사용자 프로필 저장소"가 아니라, **세계와 사용자 발화를 함께 담는 그래프 기억**이다.

## 실행방법

아래는 Windows PowerShell 기준으로, 빈 PC에서 새로 내려받아 실행하는 순서다.

### 1. 저장소 받기

```powershell
git clone https://github.com/FoggyCaligo/MACHI.git
cd MACHI\MK3
```

### 2. 가상환경 만들기

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
```

### 3. Ollama 준비

`MK3`는 적어도 임베딩 모델이 필요하고, 실제 답변까지 보려면 생성 모델도 필요하다.

```powershell
ollama serve
```

새 PowerShell 창에서:

```powershell
ollama pull nomic-embed-text
ollama pull gemma3:4b
```

### 4. 서버 실행

`MK3`는 `run.py`를 통해 Flask 앱을 띄운다.

```powershell
python run.py
```

### 5. 접속 확인

브라우저에서 아래 주소를 연다.

```text
http://127.0.0.1:5000/
```

문서와 코드를 함께 볼 때 시작점으로 좋은 파일은 아래다.

- `app/chat_pipeline.py`
- `core/activation/activation_engine.py`
- `core/thinking/thought_engine.py`
- `core/entities/conclusion_view.py`
- `docs/architecture/MK3_overview.md`
