# MACHI

MACHI는 한 사람을 장기적으로 이해하고 보조하는 **로컬 개인 AI / 인지 시스템**을 만들기 위한 프로젝트입니다.

이 저장소의 `MK` 번호는 단순한 작성 시점이 아니라, MACHI가 문제를 발견하고 구조를 다시 설계해 온 **아키텍처의 발전 단계**를 나타냅니다.

현재 기준으로는 **`MK4`가 실제로 실행하고 계속 개선하는 구현체**이며, **`MK5`는 그래프 자체가 기억뿐 아니라 사고까지 수행하는 구조를 연구하는 다음 단계**입니다.

---

## 1. 초기 목적

MACHI가 처음부터 지향한 것은 단순히 질문에 그럴듯하게 답하는 챗봇이 아니었습니다.

핵심 목표는 다음과 같습니다.

- 사용자를 장기적으로 이해할 수 있을 것
- 기억을 단순 대화 로그가 아니라 수정 가능한 구조로 유지할 것
- 언어 표면보다 그 뒤의 개념, 관계, 판단 흐름을 다룰 것
- 사용자의 데이터와 기억을 가능한 한 로컬에서 통제할 것
- 사용자를 대신 판단하기보다 사용자의 판단을 더 잘 보조할 것

구현 방법은 여러 번 바뀌었지만 이 방향은 유지되어 왔습니다.

---

## 2. 세대별 발전 과정

### IDEA1 — Cognitive Partner의 출발점

MACHI 이전 단계의 문제의식과 철학을 정리한 문서입니다.

- 장기적으로 사용자를 이해하는 AI
- 기억과 정체성의 지속성
- 단순 챗봇을 넘어선 개인 인지 보조 시스템

이후 모든 MK의 출발점이 된 개념을 담고 있습니다.

### MK1 — 초기 로컬 에이전트

MACHI를 실제로 실행 가능한 개인용 AI 형태로 만들기 시작한 첫 프로토타입입니다.

대화 모델, 로컬 실행 환경, 기억과 도구 사용을 하나의 시스템으로 묶는 기본 골격을 실험했습니다.

### MK2 — Evidence-first Memory

기억을 단순히 누적하는 것이 아니라, **근거와 수정 가능성을 가진 별도 계층**으로 다루는 방향을 실험했습니다.

장기 기억이 단순 로그에서 벗어나 이후 수정·검증될 수 있는 대상으로 발전한 단계입니다.

### MK3 — 기억 중심 대화 루프

MK2의 기억 구조를 실제 대화 흐름 안에서 사용할 수 있도록 확장하고 안정화한 단계입니다.

사용자 입력, 기억 회수, 응답 생성이 하나의 지속적인 루프 안에서 연결되기 시작했습니다.

### MK4 — 현재 실행형 MACHI

**현재 MACHI에서 가장 완성도가 높고, 실제로 계속 사용·개선하는 구현체입니다.**

MK4에서는 그래프를 사고 엔진 전체로 사용하지 않고, **수정 가능한 장기 기억과 회수 인프라**에 집중시킵니다.

실제 응답 계획, 도구 선택, 문장 생성은 LLM이 담당하고 그래프는 그 LLM이 장기적으로 사용자를 기억하고 필요한 과거 문맥을 찾도록 지원합니다.

현재 구현된 주요 요소는 다음과 같습니다.

- 사용자별 persistent memory anchor
- SQLite 기반 장기 그래프 기억
- 사용자 발화·사실·정정·검색 근거 저장
- 현재 입력과 이전 활성도를 이용한 기억 회수
- 필요 시 추가 기억을 찾는 `graph_search`
- 웹 조사 도구
- 파일 탐색·읽기·생성·수정·삭제
- PDF/DOCX 문서 읽기
- 이미지 분석
- 터미널 실행
- 도구 명세를 필요할 때만 불러오는 `tool_manual`
- 작은 로컬 모델을 위한 도구 결과·대화 문맥 압축
- 파일 작업의 탐색 → 읽기 → 수정 → 검증 흐름
- routine clarification을 내부에서 다시 처리해 모델의 자율 작업 비중을 높이는 guard

한 문장으로 표현하면 다음과 같습니다.

> **LLM을 실행 주체로 사용하면서, 수정 가능한 그래프 장기 기억과 로컬 도구를 결합한 개인용 에이전트.**

구체적인 현재 구현과 실행 방법은 [`MK4/README.md`](MK4/README.md)를 참고하세요.

### MK5 — Graph-first Thinking Research

MK4가 현실적으로 동작하는 실행형 에이전트를 만드는 단계라면, MK5는 그 다음 질문을 다룹니다.

> **지금 LLM이 담당하는 사고 자체를 그래프의 구조와 활성화가 수행하도록 만들 수 있는가?**

MK5에서 연구하는 주요 방향은 다음과 같습니다.

- 언어 표면형과 의미 노드의 분리
- 의미 그래프 중심의 기억 구조
- `WorldGraph`와 임시 사고 공간의 분리
- `TempThoughtGraph`
- goal을 기준으로 한 활성화와 구조 조정
- 그래프에서 결론 구조를 만든 뒤 언어로 변환하는 흐름
- 언어 입력을 글자 흐름과 segment 형성 단계로 분리하는 표면 계층 실험

과거에 별도 세대로 두었던 언어 표면 구조 실험은 더 이상 독립 MK로 취급하지 않고, **MK5의 언어↔개념 경계 연구에 포함되는 하위 실험**으로 정리합니다.

MK5에는 과거 graph-first 프로토타입 코드가 남아 있지만, 현재 실행형 MACHI의 기본 경로는 아닙니다. 자세한 연구 방향은 [`MK5/README.md`](MK5/README.md)를 참고하세요.

## 3. 현재 저장소 구조

```text
MACHI/
├── IDEA1/   # 초기 철학과 문제의식
├── MK1/     # 초기 로컬 에이전트
├── MK2/     # evidence-first memory
├── MK3/     # 기억 중심 대화 구조
├── MK4/     # 현재 실행형 MACHI
└── MK5/     # graph-first thinking 연구 / 프로토타입
```

현재 구현을 이해하거나 실행하려면 다음 순서로 보는 것이 가장 빠릅니다.

1. [`MK4/README.md`](MK4/README.md)
2. `MK4/run_server.py`
3. `MK4/app/`
4. `MK4/core/`
5. `MK4/tools/`

장기 연구 구조를 보려면 [`MK5/README.md`](MK5/README.md)에서 시작합니다.

## 4. 향후 발전 방향

현재 MK4는 **LLM + 그래프 장기 기억 + 도구 오케스트레이션**이라는 현실적으로 동작하는 구조에 집중합니다.

MK5의 장기 목표는 LLM이 모든 사고 과정을 독점하는 구조에서 더 나아가, **그래프의 구조와 활성화 자체가 사고 과정의 일부 또는 본체가 되는 시스템**을 만드는 것입니다.

계속 연구하는 질문은 다음과 같습니다.

- 개념의 관계와 활성화만으로 현재 사고의 초점을 표현할 수 있는가?
- 목적(goal), 현재 입력, 과거 기억이 그래프 안에서 만나면서 결론 구조가 자연스럽게 형성될 수 있는가?
- 별도의 복잡한 규칙을 계속 추가하지 않고도 그래프 구조 자체가 의미와 판단 상태를 나타낼 수 있는가?
- LLM을 사고 본체가 아니라 언어 입출력과 일부 보조 추론에 한정할 수 있는가?
- 언어 표면의 segment 형성과 의미 그래프를 어떻게 분리하면서도 자연스럽게 연결할 수 있는가?

이 방향은 아직 **현재 MK4의 구현 완료 기능으로 간주하지 않습니다.**

## MACHI가 계속 유지하는 원칙

### Local-first

기억, 사용자 모델, 개인 데이터의 소유권을 가능한 한 로컬에 둡니다.

### Structure before comfort

좋은 말투보다 먼저 구조적으로 맞는 이해와 설명을 중요하게 봅니다.

### Memory is revisable

기억은 append-only 로그가 아니라 근거와 correction에 따라 수정될 수 있어야 합니다.

### User model over shallow personalization

단순 취향 목록보다 사용자의 판단 기준과 반복되는 맥락을 장기적으로 이해하는 것을 목표로 합니다.

### The user remains the decision owner

MACHI는 사용자를 대신 결정하는 시스템이 아니라, 더 정교하게 판단할 수 있도록 돕는 시스템을 지향합니다.

## 한 문장으로 요약하면

MACHI는 **MK1 → MK2 → MK3 → MK4로 실행 가능한 로컬 개인 AI를 발전시켜 왔고, MK5에서는 그래프 자체가 기억과 사고를 수행하는 다음 인지 구조를 연구하는 프로젝트**입니다.
