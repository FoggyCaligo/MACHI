# MACHI

MACHI는 한 사람을 장기적으로 이해하고 보조하는 **로컬 개인 AI / 인지 시스템**을 만들기 위한 프로젝트입니다.

이 저장소에는 하나의 완성품만 있는 것이 아니라, 같은 목적을 향해 구조를 여러 번 다시 설계하면서 얻은 세대별 결과물이 함께 남아 있습니다.

현재 기준으로는 **`MK5`가 실제로 실행하고 계속 개선하는 구현체**이며, **그래프 자체가 사고를 수행하는 구조는 `MK4`를 중심으로 장기 연구 방향으로 정리**합니다.

---

## 1. 초기 목적

MACHI가 처음부터 지향한 것은 단순히 질문에 그럴듯하게 답하는 챗봇이 아니었습니다.

핵심 목표는 다음과 같습니다.

- 사용자를 장기적으로 이해할 수 있을 것
- 기억을 단순 대화 로그가 아니라 수정 가능한 구조로 유지할 것
- 언어 표면보다 그 뒤의 개념, 관계, 판단 흐름을 다룰 것
- 사용자의 데이터와 기억을 가능한 한 로컬에서 통제할 것
- 사용자를 대신 판단하기보다 사용자의 판단을 더 잘 보조할 것

이 목표를 구현하는 방법은 여러 번 바뀌었지만, 프로젝트의 방향 자체는 유지되어 왔습니다.

---

## 2. 지금까지 달성한 결과물

MACHI의 `MK`는 단순한 버전 번호라기보다, 문제를 발견하고 구조를 다시 설계한 **세대별 실험 결과**에 가깝습니다.

### IDEA1 — Cognitive Partner의 출발점

MACHI 이전 단계의 문제의식과 철학을 정리한 문서입니다.

- 장기적으로 사용자를 이해하는 AI
- 기억과 정체성의 지속성
- 단순한 챗봇을 넘어선 개인 인지 보조 시스템

이후 모든 MK의 출발점이 된 개념을 담고 있습니다.

### MK1 — 초기 로컬 에이전트

MACHI를 실제로 실행 가능한 개인용 AI 형태로 만들기 시작한 첫 프로토타입입니다.

대화 모델, 로컬 실행 환경, 기억과 도구 사용을 하나의 시스템으로 묶는 기본 골격을 실험했습니다.

### MK2 — Evidence-first memory

기억을 단순히 누적하는 것이 아니라, **근거와 수정 가능성을 가진 별도 계층**으로 다루는 방향을 실험했습니다.

이 단계에서 MACHI의 장기 기억은 단순 로그가 아니라, 이후 수정·검증될 수 있는 대상으로 발전했습니다.

### MK3 — 기억 중심 대화 루프

MK2의 기억 구조를 실제 대화 흐름 안에서 사용할 수 있도록 확장하고 안정화한 단계입니다.

사용자 입력, 기억 회수, 응답 생성이 하나의 지속적인 루프 안에서 연결되기 시작했습니다.

### MK4 — 그래프 자체가 사고하는 구조의 프로토타입

언어를 그래프의 본체에서 분리하고, **의미 그래프 자체가 기억뿐 아니라 사고 과정까지 담당할 수 있는가**를 실험한 세대입니다.

주요 아이디어는 다음과 같습니다.

- 언어 표면형과 의미 노드의 분리
- 의미 그래프 중심의 기억 구조
- 임시 사고 그래프(`TempThoughtGraph`)
- goal을 기준으로 한 활성화와 구조 조정
- 그래프에서 결론 구조를 만든 뒤 언어로 변환하는 흐름

이 방향은 중요한 가능성을 보여주었지만, 실제 대화 시스템의 기본 경로로 사용하기에는 구조와 파이프라인이 무거워지는 문제가 있었습니다.

그래서 현재 실행형 구현은 MK5에서 더 단순한 방향으로 전환했습니다.

다만 **그래프 자체가 사고를 수행하는 구조는 폐기한 것이 아니라 MACHI의 장기 연구 방향으로 유지**합니다. 자세한 방법론은 [`MK4/README.md`](MK4/README.md)를 참고하세요.

### MK5 — 현재 실행형 MACHI

**현재 MACHI에서 가장 완성도가 높고, 실제로 계속 사용·개선하는 구현체입니다.**

MK5는 그래프를 사고 엔진 전체로 사용하지 않고, **수정 가능한 장기 기억과 회수 인프라**에 집중시킵니다.

실제 응답 계획과 도구 선택, 문장 생성은 LLM이 담당하며, 그래프는 그 LLM이 장기적으로 사용자를 기억하고 필요한 과거 문맥을 다시 찾을 수 있도록 지원합니다.

현재 구현된 주요 요소는 다음과 같습니다.

- 사용자별 persistent memory anchor
- SQLite 기반 장기 그래프 기억
- 사용자 발화·사실·정정·검색 근거 저장
- 현재 입력과 이전 활성도를 이용한 기억 회수
- 필요 시 추가 기억을 찾는 `graph_search`
- 웹 조사 도구
- 파일 검색·읽기·생성·수정·삭제
- PDF/DOCX 문서 읽기
- 이미지 분석
- 터미널 실행
- 도구 명세를 필요할 때만 불러오는 `tool_manual`
- 최근 대화와 도구 결과를 압축하여 작은 로컬 모델의 컨텍스트를 절약하는 구조

즉 현재의 MACHI를 한 문장으로 표현하면 다음과 같습니다.

> **LLM을 실행 주체로 사용하면서, 수정 가능한 그래프 장기 기억과 로컬 도구를 결합한 개인용 에이전트.**

구체적인 현재 구현과 실행 방법은 [`MK5/README.md`](MK5/README.md)를 참고하세요.

### MK6 — 언어 표면 구조 실험

입력 언어 자체를 바로 일반 토큰으로 처리하지 않고, 문자 흐름에서 segment를 만들고 이를 별도의 개념 그래프로 넘기는 방식을 시험한 후속 실험입니다.

- `LANG_GRAPH`
- segment 형성
- `CONCEPT_GRAPH`와의 분리

현재 MACHI의 주 실행축은 MK5이며, MK6는 언어와 개념의 경계를 탐색한 별도 실험 결과로 남겨둡니다.

## 3. 현재 구현 기준점

현재 코드를 이해하거나 직접 실행하려는 경우 **MK5부터 보는 것을 권장합니다.**

```text
MACHI/
├── IDEA1/   # 초기 철학과 문제의식
├── MK1/     # 초기 로컬 에이전트
├── MK2/     # evidence-first memory
├── MK3/     # memory 중심 대화 구조
├── MK4/     # graph-first thinking 연구 / 프로토타입
├── MK5/     # 현재 실행형 MACHI
└── MK6/     # 언어 그래프 / 개념 그래프 분리 실험
```

현재 구현을 보려면:

1. [`MK5/README.md`](MK5/README.md)
2. `MK5/run_server.py`
3. `MK5/app/`
4. `MK5/core/`
5. `MK5/tools/`

순서로 보는 것이 가장 빠릅니다.

## 4. 향후 발전 방향

현재 MK5는 **LLM + 그래프 장기 기억 + 도구 오케스트레이션**이라는 현실적으로 동작하는 구조에 집중합니다.

그 다음 장기 목표는, LLM이 모든 사고 과정을 독점하는 구조에서 더 나아가 **그래프의 구조와 활성화 자체가 사고 과정의 일부 또는 본체가 되는 시스템**을 만드는 것입니다.

예를 들면 다음과 같은 질문을 계속 연구합니다.

- 개념의 관계와 활성화만으로 현재 사고의 초점을 표현할 수 있는가?
- 목적(goal), 현재 입력, 과거 기억이 그래프 안에서 만나면서 결론 구조가 자연스럽게 형성될 수 있는가?
- 별도의 복잡한 규칙을 계속 추가하지 않고도, 그래프의 구조 자체가 의미와 판단 상태를 나타낼 수 있는가?
- LLM을 사고 본체가 아니라 언어 입출력과 일부 보조 추론에 한정할 수 있는가?

이 방향은 아직 **현재 MK5의 구현 완료 기능으로 간주하지 않습니다.**

그래프 자체가 사고하는 구조에 대한 구체적인 방법론과 기존 프로토타입은 [`MK4/README.md`](MK4/README.md)에 정리합니다.

## MACHI가 계속 유지하는 원칙

세대가 바뀌어도 아래 방향은 유지합니다.

### Local-first

기억, 사용자 모델, 개인 데이터의 소유권을 가능한 한 로컬에 둡니다.

### Structure before comfort

좋은 말투보다 먼저 구조적으로 맞는 이해와 설명을 중요하게 봅니다.

### Memory is revisable

기억은 append-only 로그가 아니라 근거와 correction에 따라 수정될 수 있어야 합니다.

### User model over shallow personalization

단순 취향 목록보다 사용자의 판단 기준과 반복되는 맥락을 장기적으로 이해하는 것을 목표로 합니다.

### The user remains the decision owner

MACHI는 사용자를 대신 결정하는 시스템이 아니라, 더 정교하게 판단할 수 있도록 돕는 시스템을 지향합니다.

---

## 한 문장으로 요약하면

MACHI는 **현재는 MK5라는 실행 가능한 로컬 개인 AI를 만들고 있으며, 장기적으로는 그래프 자체가 기억과 사고를 수행하는 인지 구조까지 발전시키려는 프로젝트**입니다.
